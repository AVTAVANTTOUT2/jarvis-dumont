- CLI diagnostics use constant allowlisted names/reasons; never emit input text, personal paths, secrets or raw OS exceptions.
- Asset structural PASS, model loaded, warmup, actual synthesis/transcription, playback and human voice identity/quality are separate claims.
- Relative paths resolve against the TOML parent, not process cwd.
- Import is explicit: dry-run has no writes, independent regular files are hashed before/after and atomically published. No shared model hardlinks or production links to V1. Benchmark assets stay separate; selected STT root allows one bundle.
- One TTS request per worker. Use contextlib.aclosing and await client.close(). Cancellation stops delivery, drains the identified request under the same lock, or terminates only the owned worker on timeout/protocol uncertainty. Retain the whole PCM tail; stopping delivery is not stopping computation.
- Silero frames are exactly 512 samples at 16 kHz (32 ms), state resets per session. Continuous SoXR preserves rate-conversion state. Sample counters distinguish speech bounds, VAD finalization and hardware timestamps; replay never claims hardware latency.
- Capture is explicitly triggered and bounded. Exact unique device name is rechecked, never persist its index. Any discontinuity discards the whole take before bounded reconnection. Never modify TCC or stop V1.
- No substring blacklist of ordinary French. WER keeps accents/digits and does not equate written numbers with words; conservative critical alerts need human review. Raw speech is only in explicit private reports, never nominal rejected-speech logs.
- At least 50 independently human-recorded/transcribed samples with quiet/noise and holdout are required for qualification. Synthetic references are technical evidence only. NO_ACCEPTABLE_STT is explicit; provisional engineering choice is not homologation.
- Coordinate finite microphone smokes with a ready operator. An address-only transcript or silence timeout is not a usable full-utterance/E2E smoke; do not call the LLM or change model/VAD thresholds merely to force success. Human hearing/timbre confirmation and microphone-content validation are separate gates.
- For interactive hardware validation, hand the existing paused loopback UI to the operator so they arm locally; stop all owned processes after their feedback. An empty timed window does not prove the operator was silent. Keep manual Resume delays separate from automatic rearming latency, and preserve relative MLX-production versus controller-delivery clocks.
- Releases use a committed wheel, three final-location non-editable environments and shared verified Office assets. The installed config resolver selects sibling STT/TTS interpreters; never trust development interpreter paths from the shared TOML in production. Base Python remains an explicit external prerequisite.
- The kernel flock arbitrates one Office instance before engines/capture. Do not unlink its inode. PID/start identity and the loopback session must agree before status claims verified ownership. Activation uses the same lock, verifies checksums first and atomically replaces current; rollback retains both releases.
- A LaunchAgent starts paused, never auto-arms or restarts indefinitely. Only its exact owned plist/job may be stopped or removed; uninstall preserves private data. Metadata-only Python logs rotate with a bounded file count; no raw network trace info, speech or responses.
- Phase-specific validation request ledgers are append-only counters, shared by all real client calls. A newly authorized phase uses its own ledger, never resets the previous one. Connection traces retain only timestamps, never trace info containing headers or exceptions.
