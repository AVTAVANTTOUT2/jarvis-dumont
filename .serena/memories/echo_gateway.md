# Isolated Echo transport

Echo gateway code lives only in src/jarvis_office/echo and dedicated tests. ECHO-01 is an explicitly configured transport qualification sink; it must not start a second AI pipeline or a local microphone. Parent phase-06 runtime/service/voice files are owned by the parallel release work. Do not merge or modify those without coordination.

Protocol 1 uses separate authenticated control/audio WebSockets and 48-byte PCM headers. Control loss invalidates stream/session; new connection returns OFF. Strict sequence loss and bounded-delay policy; no replay. Pairing/config outside Git, mode 0600, explicit bind and port (never 8768 or implicit wildcard). Diagnostic tone is opt-in. Passive buffer is RAM-only with three eviction limits; policy reuses the existing address detector. Buffer-to-live-STT and shared VoiceLoop ingress/egress are not yet connected.

Install the isolated requirements.txt after uv sync --locked --extra chat; no edit to shared pyproject/lock for the parallel phase. Tests: python -m unittest discover -s tests -p test_echo.py; ruff check src/jarvis_office/echo tests/test_echo.py tests/echo_android_smoke.py; mypy src/jarvis_office/echo. Emulator harness owns only emulator-5580 plus a temporary loopback gateway and ADB reverse; software success is never physical Echo qualification.
