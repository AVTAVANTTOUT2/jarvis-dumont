# Isolated Echo transport

Echo gateway code lives only in src/jarvis_office/echo and dedicated tests. ECHO-01 is an explicitly configured transport qualification sink; it must not start a second AI pipeline or a local microphone. Parent phase-06 runtime/service/voice files are owned by the parallel release work. Do not merge or modify those without coordination.

Protocol 1 uses separate authenticated control/audio WebSockets and 48-byte PCM headers. Control loss invalidates stream/session; a new connection restores the last owner-selected mode after audio_ready when OfficeStore has echo_modes. Strict sequence loss and bounded-delay policy; no replay. Pairing/config outside Git, mode 0600, explicit bind and port (never 8768 or implicit wildcard). Diagnostic tone is opt-in. Passive buffer is RAM-only with three eviction limits; policy reuses the existing address detector. Buffer-to-live-STT and shared VoiceLoop ingress/egress are not yet connected. The control recv loop has no idle timeout; a missing application ping does not close the session.

Install the isolated requirements.txt after uv sync --locked --extra chat; no edit to shared pyproject/lock for the parallel phase. Tests: python -m unittest discover -s tests -p test_echo.py; ruff check src/jarvis_office/echo tests/test_echo.py tests/echo_android_smoke.py; mypy src/jarvis_office/echo. Emulator harness owns only emulator-5580 plus a temporary loopback gateway and ADB reverse; software success is never physical Echo qualification.

Physical tests use tests/qualify_echo_device.py with an explicit ADB address, private config/report and one selected phase. No LAN scan, no root privilege use, no reverse. Pairing uses run-as/stdin, then Android Keystore; crash or mismatched/stale instrumentation results fail. Optional private PCM capture is explicit and capped at five seconds; normal on_frame diagnostics retain numeric RMS/peak only. Synchronized first-frame age plus per-stream relative backlog reject delayed audio. Clock uncertainty and the Android capture-clock basis must accompany latency estimates. Firmware AudioRecord timestamp estimates do not qualify physical microphone latency. Permanent development gateways run from a separate non-editable wheel environment and distinct user LaunchAgent, never the phase-06 runtime or checkout.
